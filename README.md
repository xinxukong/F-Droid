## 📱 怎么用（F-Droid 客户端）
1. 打开 F-Droid → 设置 → 仓库 → ＋
2. 填地址：
   https://你的用户名.github.io/你的仓库名/repo
3. 确认添加 → 刷新仓库 → 安装

## 🐾 仓库里有啥
- 自用/内部分发 APK（都放 `repo/` 目录）
- 持续更新，上传新版本自动重建索引
- 猫猫壁纸可选，地狱把妹攻略不包教
